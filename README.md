# Java — Learning & Practice

A structured collection of Java programs documenting my journey from programming fundamentals to object-oriented programming, advanced concepts, and practical projects.

This repository serves as a long-term reference for concepts I've learned, examples I've implemented, and progress made through hands-on practice.

## Learning Roadmap

| Section                          | Topics                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `01-Fundamentals`                | Variables, data types, user input, operators, strings, and formatted output                                                           |
| `02-Control-Flow`                | Conditional statements, logical operators, loops, and nested control flow                                                             |
| `03-Methods`                     | Methods, method overloading, variable scope, and varargs                                                                              |
| `04-Arrays`                      | Arrays, searching, user-input arrays, and multidimensional arrays                                                                     |
| `05-Object-Oriented-Programming` | Classes, objects, constructors, inheritance, `super`, overriding, abstraction, interfaces, polymorphism, aggregation, and composition |
| `06-Advanced-Concepts`           | Wrapper classes, collections, generics, exception handling, file handling, dates, enums, recursion, lambdas, and concurrency          |
| `07-GUI`                         | Java Swing, components, layouts, event handling, and interactive applications                                                         |
| `08-Data-Structures`             | Linked lists, stacks, queues, dynamic arrays, hash tables, and trees                                                                  |
| `09-Algorithms`                  | Searching, sorting, recursion, and algorithmic problem-solving                                                                        |
| `10-Projects`                    | Practical programs and mini-projects applying learned concepts                                                                        |

## Repository Organization

Each section is organized by topic, with individual concepts and related supporting classes grouped together. Practical projects are kept separate from standalone learning exercises to make the codebase easier to navigate and maintain.

## Learning Resources

My Java learning journey began with [Bro Code's Java Full Course](https://www.youtube.com/watch?v=xTtL8E4LzTQ), supplemented by independent practice and experimentation.
